# 43GIIN Actividad Evaluativa 4

Proyecto de pruebas unitarias con JUnit para una aplicación básica de tienda online inspirada en Demoblaze.

## Clases bajo prueba

- Producto.java
- CarroDeLaCompra.java

## Pruebas unitarias implementadas

- testAñadirUnidadAlAlmacen
- testQuitarUnidadDelAlmacen
- testCompararProductoMasCaro
- testAñadirProductoAlCarritoAumentaTotal
- testComprarCarritoCambiaEstadoAComprado

## Ejecución

Las pruebas se ejecutan desde Visual Studio Code mediante el panel Testing, usando JUnit.
